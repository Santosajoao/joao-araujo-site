# Site João Araújo
    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera /dist para publicar (Vercel, Netlify...)

- Textos, preços, contatos e vídeos: `src/data/site.js`
- Vídeos próprios: .mp4 em `public/videos/` (take-1.mp4...) e capas em `public/images/`
- Fotos: `public/images/hero.jpg` e `public/images/palco.jpg`
- YouTube: `type: 'youtube'` e o ID do vídeo em `src`
